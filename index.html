Строфа (до 14 строк, как в оригинале)

Поле «размер»: знак - = безударный слог, ' = ударный. В строке должен быть хотя бы один ударный слог.
Поле «рифма»: буквы для обозначения рифмующихся строк (a, b, c…). У рифмующихся строк должно совпадать число безударных слогов после последнего ударного.

формат словаря (.dat)

Одна запись на строку (CRLF), кодировка CP866:

  • 1–25 — слово (или словосочетание), по левому краю, пробелы справа.
  • 26–35 — схема ударений (10 знаков): - безударный, ' ударный.
  • 36–40 — ключ рифмы (5 знаков, одинаковый у рифмующихся слов).
  • 41–42 — часть речи: N сущ., A прил., AV причастие, VН гл. наст., VП гл. прош., ?V деепричастие, ? наречие, пусто — прочее.

Файл — текстовый, итого запись обычно 41–42 байта.

формат конфига (.cfg)

Одна строка (CP866) фиксированной ширины:

  • 1–20 — имя файла словаря.
  • 21–40 — имя файла ресурсов.
  • далее для каждой строки строфы поле по 25 знаков: в начале — шаблон ударений, последний знак (не пробел) — буква рифмы.
